An entry for the [One-Line Roast: The Gadget You Use Every Day](https://make.fun/competitions/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) competition on [make.fun](https://make.fun).

## The line

> My charging cable only works at one exact angle, like it's holding my phone hostage until I agree to its terms.

## How it works

`main.ts` writes the single roast line (111 characters, no trailing newline) to `/output/entry.txt`. The competition gate requires UTF-8 text of 1–200 characters, not only whitespace.

Run locally with Node 22.18+:

```sh
node main.ts
```
